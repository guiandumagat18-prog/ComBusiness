
# TechCare Computer Shop

**Live Website:** https://guiandumagat18-prog.github.io/ComBusiness/

## About

TechCare Computer Shop is a single-page business website for computer repair, technical services, and computer sales.

Our goal is to provide reliable computer solutions, maintenance, upgrades, and quality computer products.

## Design System

### Color Palette (60-30-10)

| Role | Percentage | Color | Purpose |
|---|---|---|---|
| Dominant | 60% | #F1F5F9 | Main background |
| Secondary | 30% | #0F172A | Header, footer, dark surfaces |
| Accent | 10% | #06B6D4 | Buttons, links, highlights |

### Visual Style

**Style chosen:** Modern Minimalism

**Why I chose it:**

Modern minimalism creates a clean and professional appearance that makes computer services and products easy to browse.

### Contrast Check

- Body text: #475569
- Background: #F1F5F9
- Contrast ratio: 6.92:1
- Requirement: 4.5:1 minimum
- Tool used: WebAIM Contrast Checker
